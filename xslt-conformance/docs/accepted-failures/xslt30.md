# XSLT 3.0 (`xslt30-test`): failing cases

Every failing case is named here in backticks under a heading with its status and reason. With
`-Dxslt30.checkAccepted=true`, `XSLT30Test` fails on any failing case that is not named here, so a regression is loud
and a newly accepted failure needs a written reason. Remove an entry when its case passes. Status **Open** means
winnable later; **Accepted** means a decision not to.

The check is off by default while the XSLT engine is being written; nothing is listed yet.
